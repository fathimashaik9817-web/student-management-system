# Student Management System

## Description

Student Management System is a Python-based console application that allows usersto manage students records.
The application supports adding, vieving, searching, updating, and deleting student information.
Student datais stored in a test file for  persistent storage.
The project is organized into separate modules to make the code easier to understand, maintain, and extend.

## Features

-Add new student records
-View all student records
-Search students by ID
-Update existing student information
-Delete student records
-Validate student ID, name, age, and course
-Prevent duplicate student IDs
-Store student data in a text file
-Load existing records when the application starts
-Handle missing data files using exception handling
-Separate file handling and student operations into different modules 

## Technologies Used

-Python 3
-Fle Handling
-Python Functions
-Lists and Dictionaries
-Exception Handling
-Modular Programming
